# Сервис массовой генерации актов и оферт

Веб-приложение на Flask для генерации актов об оказании услуг в форматах DOCX и PDF по Word-шаблону.

## Что есть в проекте

- `/` — главная страница с таблицей актов.
- `/admin` — загрузка нового `.docx` шаблона (Библиотека шаблонов).
- Генерация ZIP-архива с DOCX и PDF для каждой непустой строки.
- Автоматическая нумерация актов.
- Кнопка `+ Добавить строку` копирует данные из последнего акта в новый акт.
- В каждой карточке есть кнопка `Очистить документ`, которая очищает только выбранный документ.
- Автоматическое заполнение дат: дата услуг = дата подписи + 1 день, сертификат действителен с даты подписи по дату подписи + 3 года.
- Удаление временных DOCX/PDF после упаковки в ZIP.
- Удаление ZIP с сервера после скачивания.
- Замена меток `{{FIO}}`, `{{PRICE}}` и т.д. внутри параграфов, таблиц и текстовых блоков Word, включая случаи, когда Word разбил метку на несколько runs.

## Быстрый запуск сайта

Windows:

```bat
run_windows.bat
```

Linux/macOS:

```bash
./run_linux_mac.sh
```

## Windows-приложение `.exe`

В проект добавлена desktop-обёртка на `pywebview`: Flask запускается локально внутри приложения, а интерфейс открывается в отдельном окне без браузера.

Проверить desktop-режим без сборки:

```bat
run_desktop_dev.bat
```

Собрать приложение:

```bat
build_windows_app.bat
```

Готовый файл появится здесь:

```text
dist\ActsGenerator.exe
```

В desktop-версии кнопка `Скачать ZIP` открывает системное окно выбора места сохранения. После успешного сохранения временный ZIP удаляется рядом с приложением.

Важно: для генерации PDF на компьютере всё равно должен быть установлен Microsoft Word.

## Ручная установка

```bash
cd acts_service_app
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

После запуска откройте:

- Главная страница: <http://127.0.0.1:5000/>
- Библиотека шаблонов: <http://127.0.0.1:5000/admin>

## Важно про PDF

PDF-конвертация выполняется через библиотеку `docx2pdf`. Для неё на сервере должен быть установлен Microsoft Word.

Если Word не установлен, DOCX будет создаваться, но генерация завершится ошибкой на этапе PDF с сообщением о необходимости установить Microsoft Word/docx2pdf.

## Шаблон

Основной шаблон хранится здесь:

```text
uploads/template.docx
```

Его можно заменить через «Библиотеку шаблонов» (`/admin`).

Поддерживаемые метки:

```text
{{FIO}}
{{PASSPORT}}
{{INN_EXEC}}
{{ADDRESS_EXEC}}
{{ORG_NAME}}
{{INN_ORG}}
{{ADDRESS_ORG}}
{{OWNER_FIO}}
{{PLACE}}
{{SERVICES}}
{{DATE}}
{{VOLUME}}
{{PRICE}}
{{SIGN_DATETIME}}
{{VALID_FROM}}
{{VALID_TO}}
{{CERT_ORG}}
{{CERT_EXEC}}
{{ACT_NUMBER}}
```

`{{CERT_ORG}}` и `{{CERT_EXEC}}` генерируются случайно при каждой генерации в формате UUID `8-4-4-4-12`.

## Имена файлов в ZIP

Для каждого акта создаются DOCX и PDF с одинаковой базой имени:

```text
Оферта - <SIGN_DATETIME_SHORT>-<OFFER_DATE>.3<RND2>.docx
Оферта - <SIGN_DATETIME_SHORT>-<OFFER_DATE>.3<RND2>.pdf
```

Где:

- `SIGN_DATETIME_SHORT` — дата подписи в формате `ГГГГММДДЧЧММСС`.
- `OFFER_DATE` — дата оферты в формате `ГГГГ-ММ-ДД`.
- `.3` — фиксированный символ.
- `RND2` — 2 случайные цифры.

Пример:

```text
Оферта - 20240621143752-2024-06-21.347.docx
Оферта - 20240621143752-2024-06-21.347.pdf
```
