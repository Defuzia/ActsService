# Сервис массовой генерации актов и оферт

Windows-приложение (`.exe`) для массовой генерации актов об оказании услуг и оферт
в форматах DOCX и PDF по Word-шаблонам.

## Возможности

- Три режима генерации: **Акт + Оферта**, **Только акт**, **Только оферта**.
  Сейчас работает режим **«Только акт»**; режимы с офертой пока заблокированы.
- Генерация ZIP-архива с DOCX и PDF для каждой строки.
- «Библиотека шаблонов» — загрузка отдельных Word-шаблонов для акта и оферты.
- Автоматическая нумерация документов.
- Кнопка `+ Добавить строку` копирует данные из последнего документа в новый.
- В каждой карточке есть кнопка `Очистить документ`.
- Автосвязь дат:
  - дата услуг = дата подписи + 1 день;
  - сертификат действителен с даты подписи по дату подписи + 3 года;
  - дата отправки оферты и дата подписи оферты = дата услуг − 1 день.
- Замена меток `{{FIO}}`, `{{PRICE}}` и т.д. внутри параграфов, таблиц и текстовых
  блоков Word, даже если Word разбил метку на несколько runs.

## Готовый `.exe`

Основной способ распространения — собранное Windows-приложение `ActsGenerator.exe`.

Собрать локально:

```bat
build_windows_app.bat
```

Готовое приложение появится здесь (папка, не одиночный файл):

```text
dist\ActsGenerator\ActsGenerator.exe
```

Можно также собрать через GitHub Actions (workflow `.github/workflows/build-windows-exe.yml`)
и скачать артефакт `ActsGenerator-Windows` (в нём будет ZIP с папкой приложения).

В приложении кнопка `Скачать ZIP` открывает системное окно выбора места сохранения.

**Важно:** для генерации PDF на компьютере должен быть установлен Microsoft Word.
Обычно требуется Microsoft Edge WebView2 Runtime (входит в Windows 10/11).

## Антивирус и цифровая подпись

Приложение собирается через PyInstaller и подписывается **самоподписанным
сертификатом** (self-signed). Антивирус/Защитник Windows может показывать
предупреждение о «неизвестном издателе» — это **ложное срабатывание**: в коде нет
вредоносных действий, это обычный генератор DOCX/PDF.

Чтобы убрать предупреждение на конкретном компьютере:

1. Установите сертификат в **«Доверенные издатели» (Trusted Publishers)**:
   - Запустите `certmgr.msc` → «Доверенные издатели» → «Сертификаты».
   - Импортируйте сертификат `ActsGenerator` (он создаётся при сборке в личном
     хранилище того пользователя, который собирал).
   - После этого Windows будет доверять exe, подписанному этим сертификатом.
2. Если антивирус ругается на сам файл — добавьте папку с приложением в
   исключения (Защитник Windows → Управление параметрами → Исключения).

> Честное замечание: самоподписанный сертификат снимает предупреждения только на
> компьютерах, где сертификат импортирован. Для полного доверия «везде» нужен
> платный сертификат издателя (EV) или облачная подпись (например, Azure Trusted
> Signing).

## Шаблоны

Шаблоны хранятся рядом с exe в папке `uploads/`:

```text
uploads/template.docx         — шаблон акта
uploads/template_offer.docx   — шаблон оферты
```

Их можно заменить через встроенную «Библиотеку шаблонов».

### Метки акта

```text
{{FIO}}
{{PASSPORT}}
{{INN_EXEC}}
{{ADDRESS_EXEC}}
{{ORG_NAME}}
{{INN_ORG}}
{{ADDRESS_ORG}}
{{PLACE}}
{{SERVICES}}
{{DATE}}
{{VOLUME}}
{{PRICE}}
{{SIGN_DATETIME}}
{{VALID_FROM}}
{{VALID_TO}}
{{OWNER_FIO}}
{{CERT_ORG}}
{{CERT_EXEC}}
{{ACT_NUMBER}}
```

### Метки оферты

```text
{{OFFER_SENT_DATE}}
{{EXEC_PHONE}}
{{EXEC_EMAIL}}
{{EXEC_ACCBANK}}
{{SIGN_DATETIMEOFF}}
{{CERT_ORGOFF}}
```

Плюс общие метки из списка акта (`{{FIO}}`, `{{ORG_NAME}}`, `{{PRICE}}` и т.д.).

`{{CERT_ORG}}`, `{{CERT_EXEC}}` и `{{CERT_ORGOFF}}` генерируются случайно при каждой
генерации в формате UUID `8-4-4-4-12`.

## Имена файлов в ZIP

Для каждого документа создаются DOCX и PDF с одинаковой базой имени:

```text
Акт оказанных услуг - <SIGN_DATETIME_SHORT>.docx
```

Где `SIGN_DATETIME_SHORT` — дата подписи в формате `ГГГГММДДЧЧММСС`.

Пример:

```text
Акт оказанных услуг - 20260802064213.docx
Акт оказанных услуг - 20260802064213.pdf
```
